# Proyek 72: Efek Kaca Pembesar Gambar (Image Zoom Glass)

Proyek ini adalah implementasi **Efek Kaca Pembesar Gambar (Image Zoom Glass)** interaktif yang menggunakan **HTML5, CSS3, dan Pure JavaScript (Vanilla JS)**. Cocok digunakan sebagai bahan ajar atau proyek latihan siswa SMK jurusan Software Engineering (RPL/PPLG) untuk memahami manipulasi DOM, pemrosesan koordinat event kursor, serta kalkulasi latar belakang CSS.

## 📁 Struktur File Proyek

```text
image-zoom-glass/
├── index.html   # Struktur HTML halaman web & kartu produk
